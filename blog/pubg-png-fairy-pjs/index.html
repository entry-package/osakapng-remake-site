【PUBG部門】PNG Fairy PJSドン勝キャンペーン

この記事は掲載当時の情報です。募集・イベントの開催状況や所属情報は、現在と異なる場合があります。

掲載当時の外部リンクのうち、現在の移転先を確認できないものは文字のみで掲載しています。

2018年9月22日 東京ゲームショウ2018にて開催されたPUBG JAPAN SERIES Day1 Round4にて、PNG Fairyがドン勝したことを記念してプレゼントキャンペーンを開催いたします。

キャンペーン期間

9/28~10/4(23:59)

応募方法　以下の３つのアカウントを全てフォロー＆対象のツイートのRTのみ！

1 : @PNGesportsをフォロー　

2 : @fumoshopをフォロー

3 : @gyazo_ninjaをフォロー
4 : 対象のツイートをRT

プレゼント内容
救援物資キーキャップ x 1名

Gyazo Pro + Gyazoマウスパッド x 5名

PNGユニフォーム x 1名　

計7名様にプレゼント！

・キャンペーンツイート

https://twitter.com/PNGesports/status/1045510185052037120

・救援物資キーキャップ


ネット通販サイト「ふもっふのおみせ」にて販売されているPUBGでおなじみの救援物資をモチーフにしたキーキャップになります！

このキーキャップは、「VARMILO（アミロ）」と「ZOMO（ゾモ）」というメーカーとコラボ商品となっております！

一つ一つ細かなところまで作り込まれており、お値段は少し高値ではありますが、

PUBGをする方、PUBGが好きな方は購入するしかないと思います！

ドイツ・CHERRY社製のMXスイッチの規格で製造されているキーボードの軸であれば設置可能となっております。

大人気製品で、入荷待ちが発生しております！
どうしても入手したい方はこちらから予約をしてはいかがでしょうか？

商品ページ

・Varmilo ZOMO Airdropbox Key Cap for Cherry MX Switches

・Gyazo Pro + Gyazoマウスパッド x 5名

Gyazoとは簡単に指定箇所を撮影できるスクリーンショットアプリになります。

アプリ起動->範囲選択->終了！

URLが自動的に作成されるので共有もコピー＆ペーストで簡単！

Pro版では、過去に作成したスクリーンショットをいつでも閲覧でき、画像編集も行うことが可能です！

国内外のゲーマー御用達のGyazoのPro版を使用してみませんか？

PNGのメンバーは全員がPro版を使用し、日々の練習にも活用しています！

また今回は8月に制作されたばかりのGyazoNinjaマウスパッドもセットでプレゼント！

・GyazoProについて
　https://gyazo.com/pro?lang=ja

・PNGユニフォーム x 1名

TGS2018にて開催されたPJSにて選手が実際に着用していたユニフォームと同じものを1名様にプレゼントいたします！
このユニフォームを着れば、PNFと同じようにドン勝を取ることができるかもしれません！
ユニフォームを着用して、PNGを応援しましょう！
