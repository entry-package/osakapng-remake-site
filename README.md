# OsakaPNG Website Remake Prototype

既存の Strikingly サイト `https://www.pngesports.com/` を正本として確認し、ファンがメンバー・ニュース・SNS・グッズへ進みやすいBtoC中心の試作です。

## 確認した元サイト

- HOME: NEWS&EVENTS / MEMBER / FOLLOW / CONTACT / SPONSORS / PACkage導線
- MEMBER: 桜木みゆ、らりほん、紫ノ花りお、隣ノあおこ、kira、不屈、神楽紫苑、とわとせつな
- 運営会社: 株式会社PACkage

## リメイク方針

- ファーストビューで「大阪発のゲーム・配信コミュニティ」が分かる構成へ変更
- 所属タレントをカード化し、種別フィルターを追加
- ニュース、メンバー、SNS、グッズへの導線を優先
- 仕事・提携相談は下部CONTACTに整理し、主役にしすぎない構成へ変更
- スマホ表示で余白が崩れないよう全面的に再設計
