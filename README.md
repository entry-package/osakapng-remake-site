## 多言語版（2026-10-11、未公開）

英語・簡体字中国語・繁体字中国語・韓国語のサイト案内を `/en/`、`/zh-hans/`、`/zh-hant/`、`/ko/` に追加。日本語の記事・詳細プロフィール・法的文書は原文を保ち、リンクに言語を明記しています。全記事の全文翻訳ではありません。

- 翻訳原稿: `content/i18n/overviews.json`。各翻訳配列は英語・簡体字・繁体字・韓国語の順。元ページとコミットを同ファイルに記録。事実・所属・実績を追加せず、元の案内を要約翻訳しています。
- 生成: `python3 scripts/build-i18n.py --output TARGET --inject --production`。TARGETは下記。翻訳JSONを直して再生成します。既存のページ内容を上書きする用途には使いません。
- 既存の日本語問い合わせフォームは保持。翻訳版はメール下書き作成と既存の日本語フォームへのリンクです。新しい送信処理はありません。
- 検証: `scripts/verify-i18n.py` はBeautiful SoupのあるPythonで実行。画像・相互言語リンク・canonical・sitemap・フォーム・原文保持を検証。Chromeの表示検証結果は `reports/`。
- 言語の自動転送は行いません。JavaScriptを無効にしても本文と言語切替を利用できます。
- 本番前に社長へテスト公開を提示し、確認後に同じ固定成果物を本番へ。公開前はこのブランチを本番へマージ・デプロイしないこと。
- 翻訳原稿の言語別校閲・公開環境での全リンク・フォーム実配送は未実施。

TARGET: `.`。
このブランチは配信ファイル側（main）です。開発テンプレートから再生成する際は、最新mainのリダイレクト等を保った上で翻訳生成を再実行してください。配信時はcontent・scripts・reports・.review・Gitを含めないでください。
